# LaP-titeCoursiere
La P'Tite Coursière est un service de proximité spécialisé dans l'aide ménagère, l'assistance à domicile et les services du quotidien à Yaoundé, Cameroun.  Le projet a été créé pour répondre à un besoin simple : aider les personnes et les familles qui manquent de temps en prenant en charge certaines tâches quotidiennes.
